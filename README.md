# 基金组合定投回测系统

> 一个面向个人投资者和投研人员的基金组合长期定投回测工具，本地运行、浏览器使用。

---

## 系统功能

- ✅ 支持多只基金组合（2~10只），手动输入基金代码和目标权重
- ✅ 支持 6 位基金代码（场外）和带市场后缀代码（如 `510300.SH`，场内/ETF）
- ✅ 自动通过 AkShare 获取基金历史净值数据
- ✅ 优先使用复权净值，无复权净值时回退到单位净值
- ✅ 定投频率支持：每月（默认每月10日）、每两周
- ✅ 非交易日自动顺延至下一个可用净值日
- ✅ 每期总金额按目标权重自动分配到各基金
- ✅ 与沪深300进行同金额定投基准对比
- ✅ 输出4类图表：组合市值、累计收益率、回撤曲线、基准对比
- ✅ 保存最近10次回测记录（本地 JSON）
- ✅ 支持一键复用历史回测参数
- ✅ 回测结果支持导出 CSV

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动系统

```bash
streamlit run app.py
```

### 3. 访问系统

浏览器会自动打开，或手动访问：http://localhost:8501

## 使用说明

### 输入参数

| 参数 | 说明 |
|---|---|
| 基金代码 | 6位代码（如 `000001`）或带后缀（如 `510300.SH`） |
| 目标权重 | 每只基金占组合的百分比，所有基金权重之和必须 = 100% |
| 开始日期 | 回测开始日期 |
| 结束日期 | 回测结束日期 |
| 每期定投金额 | 每次定投的组合总金额（元） |
| 定投频率 | 每月（默认每月10日）或每两周 |
| 基准对比 | 勾选后与沪深300同金额定投进行对比 |

### 输出指标

| 指标 | 说明 |
|---|---|
| 累计投入本金 | 回测期内总共投入的金额 |
| 期末组合市值 | 回测结束日的组合总市值 |
| 累计收益率 | (期末市值 - 累计投入) / 累计投入 |
| 年化收益率 | 折算为年化的简单收益率 |
| 最大回撤 | 组合市值从最高点下跌的最大幅度 |
| 定投次数 | 实际执行定投的次数 |
| 相对基准超额收益 | 组合收益率 - 基准同等定投收益率 |

## 注意事项

- **数据来源**：净值数据来自 AkShare（天天基金等），需要联网使用
- **费用**：当前版本不考虑申购费、赎回费、税费等，基金管理费已体现在净值中
- **分红**：使用复权净值时已考虑分红再投资；使用单位净值时未完整反映分红
- **历史数据**：部分较老的基金历史数据可能不完整，系统会给出提示
- **免责声明**：本工具仅供历史研究使用，不构成任何投资建议
